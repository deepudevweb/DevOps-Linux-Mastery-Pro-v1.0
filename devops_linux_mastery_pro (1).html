Zero-to-Hero Visual AWK Scripting & Alert Function Guide

Real Company Mein awk se Alert Scripts & Custom Functions Kaise Banate Hain?

Beginners aksar sochte hain ki awk sirf {print $1} ke liye hota hai. Lekin asli IT companies (SRE/DevOps) mein AWK ek poori programming language hai jisse CPU/Memory Alert Functions, HTTP 500 SLA Breach Detectors, aur DDoS IP Blockers banaye jaate hain!

STEP 1: BEGIN { } Runs ONCE at Start

Log file ki pehli line padhne se pehle sirf 1 baar chalta hai. Yahan hum alerts = 0 initialize karte hain aur Report ka Header print karte hain. 

BEGIN {
  alerts = 0
  print "=== START SCAN ==="
}
STEP 2: function name() Reusable Logic

Jaise Python/JS mein function banate hain, bilkul waise hi AWK mein function trigger_alert(srv, cpu) banate hain jo threshold check karke alert message deta hai! 

function check(srv, cpu) {
  if (cpu > 85) {
    alerts++
    return "[ALERT] " srv
  }
  return "[OK] " srv
}
STEP 3: { Main Loop } Runs on EVERY Line

File ki har line ke liye yeh block automatic chalta hai. Yahan $1 (1st column), $3 (3rd column) hum apne function mein bhejte hain. 

# Har line par function call:
{
  print check($1, $3)
}
STEP 4: END { } Runs ONCE at End

Jab poori file padh li jati hai, tab aakhir mein END block chalta hai jo Total Alerts, Total Payroll, ya IP Hit Summary print karta hai! 

END {
  print "Total Alerts:", alerts
}

1. Vi / Vim 3-Mode Formula

Beginners Vi mein isliye phaste hain kyunki wo seedha type karne lagte hain. Yaad rakhein Vi ke 3 Modes hote hain:

1. Normal Mode (Default):

File khulte hi aap Normal mode mein hote hain. Yahan dd (delete line), yy (copy line), p (paste), u (undo) kaam karta hai.

2. Insert Mode (Press i, a, o):

Kuch likhne ke liye i dabayein. Likhne ke baad wapas Normal mode mein aane ke liye Esc dabayein!

3. Command Mode (Press :):

Normal mode mein :wq (Save & Quit), :q! (Bina save kiye bahar), :set nu (Line numbers).

2. Hard Link vs Soft Link (ln)

Interview ka sabse favourite sawaal! Asli data disk par **Inode** mein hota hai:

Hard Link (ln file1 hard1)

• Dono files ka **Inode Number SAME** hota hai.
• Agar asli `file1` delete bhi ho jaye, tab bhi `hard1` mein **data 100% safe** rehta hai!

Soft Link (ln -s file1 soft1)

• Windows ke Desktop Shortcut jaisa.
• Inode alag hota hai. Agar asli `file1` delete ho gayi, toh `soft1` **Broken (Dangling) Link** ban jata hai!

3. Crontab 5-Star (* * * * *) Trick

Automatic backup ya script chalane ke liye 5 stars ka kram chhote se bada samay hota hai:

*   *   *   *   *
1st * = Minute (0 - 59)
2nd * = Hour (0 - 23)
3rd * = Day of Month (1 - 31)
4th * = Month (1 - 12)
5th * = Day of Week (0=Sun to 6=Sat)
Example: 0 2 * * * /home/devops/backup.sh (Roz raat 2:00 AM)
4. AWK Real-Company Scripting, Custom Functions & Alert Engine Formula

Asli companies mein `awk` sirf column print karne ke liye nahi, balki **Real-Time Log Alerting, SLA Breach Detection aur Custom Functions** banane ke liye use hota hai! Iske 3 हिस्से samjhein:

1. BEGIN { ... } Block

File ki pehli line padhne se **pehle** sirf 1 baar chalta hai. Yahan variables (`count=0`, `FS=","`) ya Report Header set karte hain.

BEGIN { print "=== CPU ALERT REPORT ===" }
2. function alert_check(...) + Main { }

Har line par custom function call karke threshold check karte hain (jaise CPU > 85% ya HTTP 500):

function alert(srv,cpu){ if(cpu>80) return "CRITICAL: " srv; return "OK: " srv }
3. END { ... } & -f script.awk

Saari lines khatam hone ke **baad** Final Summary / Alert Count print karta hai. Badi scripts ko `.awk` file mein rakh kar `-f` se chalate hain:

awk -f alert_monitor.awk server_metrics.log
